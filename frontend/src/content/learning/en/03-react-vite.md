# Interface as composition

React splits a screen into pieces with a clear responsibility. A component receives data and emits actions; state decides what is visible. TypeScript turns ambiguous contracts into errors before runtime.

## Exercise

Split a chat into model selector, history, message, and input box. Decide where each state belongs.

## Check

Distinguish local component state from API-fetched data.

## Common mistake

Duplicating state across components and losing the source of truth.
