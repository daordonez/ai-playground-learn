# The MVP is not the end

Launching means validating that the path works, progress survives, and recovery exists. The backlog can later activate OIDC, multiple users, real Azure Foundry, and PostgreSQL when load requires it.

## Exercise

Write a five-step runbook for an unresponsive application.

## Check

Distinguish an application, volume, network, registry, or external-provider failure.

## Common mistake

Calling an MVP done without backup, health check, or identifiable deployed version.
