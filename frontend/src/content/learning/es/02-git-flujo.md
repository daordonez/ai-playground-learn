# El repositorio es el contrato

En desarrollo, el commit no solo guarda trabajo: documenta una decisión que puede probarse, revisarse y desplegarse. Trabaja en ramas cortas y procura que cada pull request entregue una unidad verificable.

## Ejercicio

Propón tres commits para añadir una pantalla de perfil: contrato API, interfaz y prueba.

## Verificación

Cada commit puede describirse en una frase y no mezcla refactorización con una función nueva.

## Error frecuente

Guardar una tarde completa de cambios en un único commit imposible de revisar.
