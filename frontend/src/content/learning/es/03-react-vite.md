# La interfaz como composición

React divide una pantalla en piezas con responsabilidad clara. Un componente recibe datos y emite acciones; el estado determina qué se ve. TypeScript convierte los contratos ambiguos en errores detectables antes de ejecutar.

## Ejercicio

Separa un chat en selector de modelo, historial, mensaje y caja de entrada. Decide qué estado pertenece a cada pieza.

## Verificación

Puedes distinguir estado local de un componente y datos recuperados desde la API.

## Error frecuente

Duplicar el mismo estado en varios componentes y perder la fuente de verdad.
